## 阅读与复现

解压后，PDF 位于 `preview/pdf/classical-statistical-learning.pdf`，网页入口为 `preview/html/index.html`。PDF 可以离线阅读；HTML 的 MathJax 公式渲染需要联网。本次完成 HTML 构建与静态链接检查，未完成真实浏览器中的 MathJax 显示检查。

安装 Quarto 与含中文支持的 TeX 环境，在项目目录运行：

```bash
quarto render --to html
quarto render --to pdf --output-dir _pdf
```

本次排版使用 TeX Live 2023 及相匹配的 ctex/xeCJK 组件。配置由 ctex 处理中文，以 `babel-lang: english` 避免旧版 babel 的中文语言标识目录兼容问题，并显式保留中文附录标题。

重绘插图：

```bash
python scripts/draw_figures.py
```

需安装 numpy、matplotlib；正文渲染不运行 Python。
