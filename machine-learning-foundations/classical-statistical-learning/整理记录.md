## 主要数学纠错

| 位置 | 原稿问题 | 处理 |
|---|---|---|
| 线性回归 | 观测直接写 Y=Xw；半正定似乎即可逆 | 区分观测/预测/噪声；明确列满秩和奇异/病态区别 |
| 岭回归 | 可逆条件、先验尺度关系未明确 | 明确 lambda>0 和 lambda=sigma²/tau²；惩罚/约束需匹配 |
| cheatsheet | L1/L2 的高斯/Laplace 先验对应写反 | L2 对应高斯，L1 对应 Laplace |
| 感知机 | 将非光滑损失笼统称为可导 | 使用次梯度，并解释零间隔更新 |
| GDA | 似然叫 MAP；协方差求导中随意交换矩阵次序 | 改为 MLE；改用精度矩阵求导，保持正确乘法次序 |
| 朴素贝叶斯 | 将 p(x,y) 写成条件概率乘积 | 改为 p(x|y)；强调联合条件独立，非只有两两独立 |
| Fisher | 协方差与散度的权重混用 | 保留原稿 S0+S1，同时解释与标准加权散度的区别 |
| SVM | 内层最小化同时写参数与样本；对偶等式漏项 | 分清 min_i 和 max_(w,b)；保留 sum alpha_i y_i=0 |
| 软间隔 | hinge 目标仍附硬约束；松弛直接等于 1-margin | 去掉硬约束；最优松弛为 max(0,1-margin) |
| Slater | 有严格可行点似乎无条件推出强对偶；无限乘子与间隙混淆 | 明确凸性、相对内部、仿射等式；区分零间隙与对偶取得 |
| 对偶几何 | 直接将精确像集 G 当作凸集 | 使用向上向右扩展集合进行凸分离直觉；图例全部可计算 |
| PCA | 维度极限趋于 0；单位且独立的基就可分别优化 | 改为维度趋于无穷；约束 U^T U=I，不能独立重复选第一方向 |
| 指数族 | 充分统计量“含所有信息”；方差为正所以严格凸 | 限定为关于参数的信息；协方差半正定，仅推出凸 |
| 最大熵 | 对单个 p(x) 求导仍带全局求和，以总和为零推每项零 | 逐分量求偏导；区分支持集与样本数；补支持与约束条件 |
| EM | 参数等于期望值；ELBO 期望漏 log | 区分 argmax 与 Q；修复 log；保留不下降而非每次增大 |
| GEM | 将近似后验与广义 EM 混为一谈 | 区分 GEM、变分 EM、MCEM 及各自保证 |
| GMM | 完整数据叫完整参数；权重求导求和缺步骤 | 修正术语，补乘 pi_k 再求和；补均值和协方差更新 |
| 图模型 | 边直接是条件概率；有向/无向只能离散 | 分清结构与变量类型 |
| d-separation | 碰撞节点的后代漏写；Markov 毯漏共同父节点 | 补齐路径阻断规则、父/子/配偶节点 |
| MRF | Markov 性质无条件等价；最大/极大团混用 | 补正性条件；使用极大团 |
| 因子图 | 转换后必然无环 | 给出大联合因子与多个二元因子的区别 |
| BP | 凭空乘末端 p(e)，消息下标与归一化缺失 | 用一致的树势函数形式完整重写保留推导路线 |
| 高斯网络 | 高斯边缘推出联合高斯；条件均值漏负号和中心化 | 明确联合高斯假设，按精度矩阵配方 |
| HMM | 前向 o_t/o_(t+1) 混用；观测/状态路径混用 | 统一时间下标、枚举对象，补边界、回溯与更新 |
| CRF | 边缘观测独立误解；特征数上界错误 | 强调条件独立；任意输入特征不受标签数一般上界限制 |
| MCMC | 要求独立；平稳等于有限步到达；特征值只比较大小 | 分清平稳/收敛/遍历估计；模长、周期性和渐近性 |
| MH | 接受后似乎立即服从目标 | 说明初值与遍历条件，并明确拒绝状态也要记录 |
| Gibbs | 接受率 1 似乎保证快混合或整轮可逆 | 限定单坐标更新；整轮保持平稳但未必可逆 |
