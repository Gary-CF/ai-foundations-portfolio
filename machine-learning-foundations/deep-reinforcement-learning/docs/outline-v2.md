## 2. 七篇、二十二章

### 第一篇：决策问题与经典强化学习基础

**第 1 章　强化学习的问题设定与算法地图〔A〕**

- 交互闭环：状态、观察、动作、奖励、轨迹、策略。
- 即时奖励、累计回报与优化目标的区别；信用分配与探索为什么出现。
- MDP 与 POMDP；有限时域与折扣无限时域，明确各自边界条件。
- 分类坐标：预测 / 控制，model-free / model-based，on-policy / off-policy，online / offline。
- 最小例子：两状态、两动作的小环境，逐项写出问题定义。
- 本章产物：一张算法分类表和一份全书符号表。

**第 2 章　价值函数、Bellman 方程与动态规划〔A〕**

- 从回报递推得到 V、Q、A 的定义与相互关系。
- Bellman 期望方程和最优方程：分别固定了什么、优化了什么。
- 策略评估、策略改进、策略迭代、价值迭代与广义策略迭代。
- 折扣表格情形的压缩映射、不动点及收敛；明确假设。
- 最小例子：手算一次策略评估和一次策略改进。
- 必须推导：Bellman 递推、策略改进的核心论证；不把表格保证直接推广到神经网络。

来源入口：[白板 MDP](https://www.bilibili.com/video/BV1RA411q7wt/)；[白板动态规划](https://www.bilibili.com/video/BV1nV411k7ve?p=3)。

**第 3 章　未知环境：Monte Carlo、TD 与表格控制〔A〕**

- 从“已知模型求期望”转为“用轨迹样本估计”。
- MC 与 TD(0)：完整回报和自举目标；偏差、方差、更新时机。
- SARSA、Expected SARSA、Q-learning 的更新目标对照。
- 行为策略与目标策略；为什么 Q-learning 能使用其他行为策略的数据。
- ε-greedy、覆盖条件与学习率条件；收敛结论只在相应假设下使用。
- 最小例子：同一条轨迹分别计算 MC、TD 与 Q-learning 更新。

**第 4 章　多步估计、重要性采样与数据复用〔A/B〕**

- n-step return、λ-return；资格迹作为延伸。
- 重要性采样的支持集条件；普通与自归一化估计的差异。
- 动作概率比、整条轨迹概率比、状态分布修正不是同一个对象。
- 用偏差—方差权衡理解截断、归一化与多步目标。
- 本章为 GAE、PPO 和离线策略评估提供统一工具；不在各算法章重复证明。

### 第二篇：从表格方法到深度价值学习

**第 5 章　函数近似与深度强化学习的不稳定性〔A〕**

- 用参数化函数表示价值或策略；线性近似到神经网络。
- 回归目标与采样分布；TD 半梯度与完整梯度的区别。
- 函数近似、自举和 off-policy 的共同作用；移动目标与相关样本。
- “训练误差下降”为什么不等于“策略回报提高”。
- 先给简单失效现象，严谨反例与投影算子放扩展框。

**第 6 章　DQN 与离散动作的深度控制〔A〕**

- 从 fitted Q iteration / Q-learning 到 DQN 的训练循环。
- 经验回放、目标网络与目标值停止梯度。
- Double DQN：动作选择与价值评估分离，解释过估计来源。
- 真正终止与外部时间截断如何影响 bootstrap；始终与任务定义对齐。
- Dueling、优先回放、回报分布建模（distributional RL）列为 C 级扩展，不堆进首次主线。
- 本章产物：目标值对照表、训练伪代码、一次小环境消融。

对应来源：[CS285 Section 4：DQN 与 SAC](https://rail.eecs.berkeley.edu/deeprlcourse/static/sections/section-4.pdf)。

### 第三篇：直接优化策略

**第 7 章　策略梯度与 REINFORCE〔A〕**

- 为什么可以直接优化策略；轨迹概率如何依赖策略参数。
- log-derivative trick、因果性、reward-to-go 与策略梯度定理。
- baseline 为什么可以不改变梯度期望；无偏性的具体条件。
- 离散策略与高斯策略；目标函数和代码 loss 的正负号。
- 最小例子：两动作 bandit，手算一次梯度并核对更新方向。

**第 8 章　Actor–Critic、优势估计与 GAE〔A〕**

- 用价值估计降低策略梯度方差，以及引入的估计误差。
- Actor 和 Critic 分别优化什么、各自使用哪些数据。
- TD residual、多步优势到 GAE 的关系；γ 与 λ 的不同作用。
- advantage detach、value target、共享网络与损失项。
- 避免把 Actor–Critic 当成一个特定算法，或默认它一定是 on-policy。

白板入口：[REINFORCE](https://www.bilibili.com/video/BV1xb4y1W7Ye/)；[Baseline 与 Actor–Critic](https://www.bilibili.com/video/BV1RF411x7oS/)。

**第 9 章　稳定策略改进：自然梯度、TRPO 与 PPO〔A/B〕**

- 大步更新为什么可能导致性能崩溃；先解释旧策略采样的代理目标。
- 性能差异、状态访问分布变化、重要性比值与 KL 约束。
- 自然梯度与 TRPO 的几何直觉〔B〕；完整二阶实现〔C〕。
- PPO clipping 在不同优势符号下的作用；它不提供硬 KL 约束。
- 多轮 minibatch 更新、旧 log-prob、熵、clip fraction、KL 诊断。
- 本章产物：PPO 逐项公式注释和一次完整更新的数据流。

### 第四篇：正则化、推断与连续控制

**第 10 章　最大熵强化学习与控制即推断〔A/B〕**

- 为什么策略目标里加入熵；温度参数控制什么。
- soft Bellman backup、soft value 与随机最优策略。
- 最优性变量、轨迹后验、变分推断与 ELBO 的连接〔B〕。
- 随机动力学下直接后验推断的局限与受约束变分处理〔B〕。
- 熵奖励和相对参考策略的 KL 正则分别起什么作用。
- VI 只保留本章需要的内容；一般 VI 推导放数学附录或外部交叉引用。

**第 11 章　连续动作与 Off-policy Actor–Critic〔A/B〕**

- 连续动作为什么使 Q 值最大化困难；用 Actor 近似选择动作。
- DDPG 与 TD3 作为确定性策略支线〔B〕。
- SAC 作为随机策略主线〔A〕：重参数化、双 Q、温度与目标网络。
- tanh 变换后的概率密度修正；Critic、Actor 和温度更新的数据依赖。
- 比较 PPO 与 SAC 的数据使用和稳定化方法，不做脱离任务的优劣排名。

SAC 的课程依据见 [Section 4](https://rail.eecs.berkeley.edu/deeprlcourse/static/sections/section-4.pdf)；DDPG / TD3 在本框架中承担补充比较的角色。

### 第五篇：示范、模型与固定数据

**第 12 章　模仿学习：BC、分布偏移与 DAgger〔A〕**

- 有专家示范时如何把决策转为监督学习；BC 的目标。

**第 13 章　规划、模型式强化学习与世界模型〔B〕**

- 已知模型下规划，学习模型后再规划：区分两个问题。

- 隐空间世界模型作为延伸；具体大型系统另设专题。
- MCTS：选择、扩展、模拟、回传；与连续控制中的 MPC 分支对照。

白板 MCTS 入口：[规划与学习—MCTS](https://www.bilibili.com/video/BV1s5411D7JT/)。模型式部分对齐 CS285 L15–16。

**第 14 章　离线强化学习：覆盖、分布偏移与保守性〔A/B〕**

- Offline RL 的固定数据限制；与 off-policy 的区别。
- 未见动作的价值误差为什么会被策略优化放大。
- 三条机制：约束策略、悲观估值、避免更新时查询数据外动作。
- BC / SAC+BC 作为基线，CQL 与 IQL 作为不同机制的代表。
- IQL：expectile 价值回归与优势加权策略提取〔B〕。
- 离线策略评估独立成节；不能用训练集价值估计替代真实效果证据。

依据：[CS285 L17](https://rail.eecs.berkeley.edu/deeprlcourse/static/slides/lec-17.pdf)。

**第 15 章　表达能力更强的策略与 Offline-to-Online〔B/C〕**

## 6. 每章统一写作骨架

1. 本章解决什么问题：上一章的方法在哪里不够用。
2. 一个最小例子：优先复用同一个小 MDP，减少额外设定。
3. 对象与假设：符号、数据分布、时域与模型可用性。
4. 核心机制与推导：每步写明条件，不跳过期望、梯度与采样分布的变化。
5. 算法和数据流：输入、估计目标、更新对象、停止梯度、输出。
6. 比较与失效条件：只比较相邻的两三种方法。
7. 自测与实现检查：能否手算、能否解释、能否核对一轮更新。
8. 本章工具箱：少量关键公式、适用条件和常见误区。
9. 来源索引：讲次 / 视频入口 / 原始论文；后补内容单独标记。

每章明确 A/B/C 层级。完整推导只在一个权威位置维护，其他章节引用它；cheatsheet 保留公式与条件，不重复整段正文。
