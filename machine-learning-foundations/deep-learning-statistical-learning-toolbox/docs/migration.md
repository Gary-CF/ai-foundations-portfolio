## 构建与使用说明

在项目根目录执行：

```bash
quarto preview --to html
quarto render --to html
quarto render --to pdf --output-dir _pdf
```

交付包额外包含 `_book/` 和 `_pdf/` 的本次构建结果，便于直接查看；它们属于生成产物，已在 Git 忽略规则中列出。

PDF 中文由 `ctexbook` 和 Fandol 字体负责；PDF 格式局部使用 `lang: en` 避免旧版 Babel 对 `chinese-hans` 目录标记的兼容问题，目录标题单独设为“目录”，HTML 仍使用中文界面。
